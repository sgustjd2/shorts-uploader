shorts-uploader

shorts-uploader는 개인 YouTube 채널에 제작한 쇼츠 영상을 업로드하기 위한 개인용 도구입니다. 영상은 사용자가 직접 실행한 로컬 프로그램에서 만들어지며, 업로드는 사용자가 본인의 Google 계정으로 승인한 뒤에만 이루어집니다.

이 앱이 하는 일

  • 사용자의 YouTube 채널에 동영상을 업로드합니다 (YouTube Data API v3, youtube.upload 권한만 사용).
  • 다른 사용자의 데이터를 열람하거나 수집하지 않습니다.
  • 별도의 서버나 데이터베이스가 없으며, 모든 처리는 사용자의 컴퓨터에서 이루어집니다.
