개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 17일

shorts-uploader(이하 "앱")는 사용자 본인의 YouTube 채널에 영상을 업로드하는 개인용 도구입니다. 이 방침은 앱이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 앱이 접근하는 데이터

사용자가 Google 계정으로 승인하면 앱은 다음 권한 하나만 사용합니다.

  • https://www.googleapis.com/auth/youtube.upload — 사용자의 YouTube 채널에 동영상을 업로드

앱은 이 권한으로 사용자의 동영상, 재생목록, 구독, 댓글 등 기존 데이터를 읽거나 수정하지 않습니다.

2. 데이터의 저장과 이용

  • 승인 후 발급되는 OAuth 토큰은 사용자 컴퓨터의 로컬 파일에만 저장됩니다.
  • 앱에는 자체 서버나 데이터베이스가 없습니다. 개발자는 사용자의 Google 데이터를 수집, 저장, 열람하지 않습니다.
  • 토큰과 사용자 데이터는 업로드 기능을 제공하는 목적 외에는 사용하지 않습니다.

3. 제3자 제공

앱은 사용자 데이터를 제3자에게 판매, 공유, 이전하지 않으며, 광고나 사용자 프로파일링에 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

앱의 Google API 정보 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. YouTube API 서비스

앱은 YouTube API 서비스를 사용하며, 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침에 구속됩니다.

6. 접근 권한 해제 및 데이터 삭제

  • 사용자는 언제든지 Google 계정의 앱 접근 권한 페이지에서 앱의 접근 권한을 해제할 수 있습니다.
  • 로컬에 저장된 토큰 파일을 삭제하면 앱에 남은 인증 정보도 모두 사라집니다.

7. 방침의 변경

이 방침이 변경되면 이 페이지에 게시하고 시행일을 갱신합니다.
